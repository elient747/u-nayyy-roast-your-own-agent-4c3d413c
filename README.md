One line roasting the AI agent our own team built — the harshest, funniest line takes the reward.

## Run it

```sh
python3 -P -s main.py
```

Writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
